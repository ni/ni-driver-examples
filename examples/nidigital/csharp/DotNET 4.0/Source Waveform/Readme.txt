NI-Digital Source Waveform Example

What does this example show?
NIDigital.SourceWaveform demonstrates the use of the NI-Digital Pattern Driver API to configure and create a source waveform using source memory.

What are the prerequisites for running this example?
- NI-Digital Pattern Driver software
- .NET Framework 4.0 or 4.5.
- A compatible digital pattern instrument
