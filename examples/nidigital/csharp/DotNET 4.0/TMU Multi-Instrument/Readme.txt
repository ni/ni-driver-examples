NI-Digital TMU Multi-Instrument Example

What does this example show?
NIDigital.TmuMultiInstrument demonstrates the use of the NI-Digital Pattern Driver API to work with TMU resources in a multi-instrument session. It shows how TMU contexts are device-qualified, how to select TMU resources from different devices, and how each device's TMU operates independently for parallel measurements.

What are the prerequisites for running this example?
- NI-Digital Pattern Driver software
- .NET Framework 4.0 or 4.5.
- Two compatible digital pattern instruments (PXIe-6571 or similar with TMU support)
