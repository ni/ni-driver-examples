NI-Digital TMU Debounce Example

What does this example show?
NIDigital.TmuDebounce demonstrates the use of the NI-Digital Pattern Driver API to configure TMU input debounce filtering. It shows the constraint that when start and stop sources are the same channel, debounce times must be equal, and that when sources are different channels, debounce times can be configured independently.

What are the prerequisites for running this example?
- NI-Digital Pattern Driver software
- .NET Framework 4.0 or 4.5.
- A compatible digital pattern instrument (PXIe-6571 or similar with TMU support)
