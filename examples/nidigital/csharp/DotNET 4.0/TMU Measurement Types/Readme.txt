NI-Digital TMU Measurement Types Example

What does this example show?
NIDigital.TmuMeasurementTypes demonstrates how to perform common TMU measurement types using the NI-Digital Pattern Driver API. It shows three measurement configurations: Period (rising-edge to rising-edge on the same channel), Duty Cycle High (rising-edge to falling-edge on the same channel), and Skew (same event on two different channels). Each measurement uses Edge arm to guarantee deterministic results.

What are the prerequisites for running this example?
- NI-Digital Pattern Driver software
- .NET Framework 4.0 or 4.5.
- A compatible digital pattern instrument (PXIe-6571 or similar with TMU support)
