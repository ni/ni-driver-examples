NI-Digital Select Pin Function Example

What does this example show?
NIDigital.SelectPinFunction demonstrates the use of the NI-Digital Pattern Driver API to switch between different pin selected functions on your digital pattern instrument.

What are the prerequisites for running this example?
- NI-Digital Pattern Driver software
- .NET Framework 4.0 or 4.5.
- A compatible digital pattern instrument
