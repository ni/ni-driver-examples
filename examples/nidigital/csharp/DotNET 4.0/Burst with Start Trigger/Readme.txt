NI-Digital Burst with Start Trigger Example

What does this example show?
NIDigital.BurstWithStartTrigger demonstrates the use of the NI-Digital Pattern Driver API to create and configure a session and burst a pattern from a digital pattern instrument.

What are the prerequisites for running this example?
- NI-Digital Pattern Driver software
- .NET Framework 4.0 or 4.5.
- A compatible digital pattern instrument
