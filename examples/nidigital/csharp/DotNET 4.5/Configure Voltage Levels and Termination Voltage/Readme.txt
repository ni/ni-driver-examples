NI-Digital Configure Voltage Levels and Termination Voltage Example

What does this example show?
NIDigital.ConfigureLevelsAndTermination demonstrates the use of the NI-Digital Pattern Driver API to create a session, configure various voltage levels, and burst a pattern.

What are the prerequisites for running this example?
- NI-Digital Pattern Driver software
- .NET Framework 4.0 or 4.5.
- A compatible digital pattern instrument
