NI-Digital TDR Measurement Example

What does this example show?
NIDigital.TdrMeasurement demonstrates the use of the NI-Digital Pattern Driver API to create an instrument session and use Time-Domain Reflectometry (TDR) to find offsets on each physical channel defined in the pin group.

What are the prerequisites for running this example?
- NI-Digital Pattern Driver software
- .NET Framework 4.0 or 4.5.
- A compatible digital pattern instrument
