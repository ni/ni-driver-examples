NI-Digital TMU Getting Started Example

What does this example show?
NIDigital.TmuGettingStarted demonstrates the minimal workflow to configure and perform a Time Measurement Unit (TMU) measurement using the NI-Digital Pattern Driver API. It walks through every required step from session initialization through measurement acquisition and cleanup, performing a simple period measurement with Immediate arm.

This is the simplest possible TMU example. For arm type comparison, multi-measurement workflows, debounce filtering, or multi-instrument sessions, see the other TMU examples.

What are the prerequisites for running this example?
- NI-Digital Pattern Driver software
- .NET Framework 4.0 or 4.5.
- A compatible digital pattern instrument (PXIe-6571 or similar with TMU support)
