NI-Digital Load Sheets and Burst Example

What does this example show?
NIDigital.LoadSheetsAndBurst demonstrates the use of the NI-Digital Pattern Driver API to create a session, configure by loading sheets, and burst a pattern from a digital pattern instrument.

What are the prerequisites for running this example?
- NI-Digital Pattern Driver software
- .NET Framework 4.0 or 4.5.
- A compatible digital pattern instrument
