NI-Digital Loopback and Compare Example

What does this example show?
NIDigital.LoopbackAndCompare demonstrates the use of the NI-Digital Pattern Driver API to create and configure a session, burst a pattern from a digital pattern instrument, and do a loop back and compare by checking for pass/fail conditions.

What are the prerequisites for running this example?
- NI-Digital Pattern Driver software
- .NET Framework 4.0 or 4.5.
- A compatible digital pattern instrument
