NI-Digital PPMU Source and Measure Example

What does this example show?
NIDigital.PpmuSourceAndMeasure demonstrates the use of the NI-Digital Pattern Driver API to configure and source or measure voltage and current using the PPMU of a digital pattern instrument.

What are the prerequisites for running this example?
- NI-Digital Pattern Driver software
- .NET Framework 4.0 or 4.5.
- A compatible digital pattern instrument
