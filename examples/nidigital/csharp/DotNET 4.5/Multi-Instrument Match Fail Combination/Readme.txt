NI-Digital Multi-Instrument Match Fail Combination Example

What does this example show?
NIDigital.MultiInstrumentMatchFailCombination demonstrates the use of the NI-Digital Pattern Driver API to set up multiple instruments for synchronized operation when a pattern is burst on the instruments and a match fail combination is detected.

What are the prerequisites for running this example?
- NI-Digital Pattern Driver software
- NI-Sync driver software.
- .NET Framework 4.0 or 4.5.
- Two or more compatible digital pattern instruments
- A compatible NI-Sync instrument.
