NI-Digital Burst Pattern with Scan Example

What does this example show?
NIDigital.BurstPatternWithScan demonstrates bursting a pattern that uses the
scan opcode and calling the History RAM Fetch Scan Cycle Numbers API.

What are the prerequisites for running this example?
- NI-Digital Pattern Driver software
- .NET Framework 4.0 or 4.5.
- A compatible digital pattern instrument
