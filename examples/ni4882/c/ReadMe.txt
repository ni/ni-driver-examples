The sample applications help you learn and understand key concepts of
how to use the NI-488.2 API. You can use these applications as
starting points for your applications.

The C sample applications are Windows console applications. They
illustrate how to use the NI-488.2 API. A Windows console application
is a Windows application which uses text-based input and output, not 
a graphical interface.  This allows you to quickly create a Windows
application by using simple input and output functions like printf 
and scanf.
