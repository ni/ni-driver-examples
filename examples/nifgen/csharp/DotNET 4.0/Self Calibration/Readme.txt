Self Calibration Example

What does this example show?
NIFgen.SelfCalibration demonstrates the use of the NIFgen.NET API to perform self-calibration on the instrument.
Note: Refer to the specifications document for your NI signal generator to determine whether the features and values used in this example are supported.

What are the prerequisites for running this example?
- NI-FGEN 15.0 (or later) instrument driver
- NI-FGEN .NET API
- .NET Framework 4.0 or 4.5
- A compatible NI signal generator
