Example Title:         	 Voltage Measurement
                         
Example Filename:        VoltageMeasurement.sln
                         
Category:                NI-DMM (Digital Multimeters)
                         
Description:             The application demonstrates how to make measurements
			 using the .NET class library.The application configures 
			 the DMM for DC Voltage measurement,acquires a reading and 
			 displays the aquired reading to the user.
                         
Required Software:       NI-DMM .NET class library.
                         
Programming Language:    Visual C#
                         
Driver Name:             NI-DMM
                         
Driver Version:          3.0 (or later)
