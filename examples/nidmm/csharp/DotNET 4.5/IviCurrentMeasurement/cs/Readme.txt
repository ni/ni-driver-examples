Example Title:         	 IVI Current Measurement
                         
Example Filename:        IviCurrentMeasurement.sln
                         
Category:                NI-DMM (Digital Multimeters)
                         
Description:             The example demonstrates how to make measurements
			 in an IVI application.An IVI session is created,the session is

			 displayed.
                         
Required Software:       NI-DMM .NET class library.
                         
Programming Language:    Visual C#
                         
Driver Name:             NI-DMM
                         
Driver Version:          3.0 (or later)
