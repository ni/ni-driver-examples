Get and Set Image Example

Overview:
This example demonstrates how to get and set images to RT targets.

Requirements:
NI System Configuration

Instructions:
1. Run the example.
2. Enter the RT target and the user name and password, if necessary.
3. Specify the location of the image.
4. Specify whether to get or set the image.
5. If getting the image, optionally set the image metadata.
6. If setting the image, specify the network interface settings.
7. Press "Get/Set Image".
