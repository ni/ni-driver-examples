# About

The NI Driver Examples repository contains example code for text-based languages for NI drivers intended as reference.

This repository is a read-only public mirror of the examples installed by NI drivers. It exists to provide visibility to example code and allow users access without requiring installation of NI drivers.

This repository is not the canonical source of truth.

## Usage

You are free to:

- Clone the repository
- Browse source code
- Use the contents in accordance with the project's license

Example:

`git clone https://github.com/ni/ni-driver-examples.git`
